# DopaLess プライバシーポリシー

GitHub Pages向けの静的ページです。`index.html`だけで表示でき、ビルドや追加ライブラリは不要です。

## 公開手順

1. 本文を確認し、`index.html`を上記リポジトリの`main`ブランチの直下に追加する。
2. リポジトリのSettings → Pagesを開く。
3. SourceでDeploy from a branch、Branchでmain、フォルダで/(root)を選びSaveする。
4. Pagesに表示された公開URLを開き、本文と問い合わせ先を確認する。
5. アプリの「プライバシーポリシー」リンクとApp Store ConnectのプライバシーポリシーURLに、確認済みの公開URLを設定する。

公開URLの予定： https://chitana1712.github.io/dopaless-privacy/

公開日が変わる場合は、本文の制定日・最終更新日も実際の日付に合わせてください。

## 記載内容の確認

- アプリ内の設定情報は端末内で保存し、本体とMonitor拡張が共有する。
- 権限取り消し時は対象選択・制限・監視を解除する。曜日と開始・終了時刻は保持する。
- 問い合わせメールで受け取る情報と、GitHub Pagesによるアクセス情報の取り扱いも説明する。
- 機能やデータの取り扱いを変更したら本文を見直す。
